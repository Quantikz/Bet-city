# Bet City

Browser-first 3D social betting game prototype.

## MVP
- Stylized 3D town
- Lucky Shop
- Test BET wallet
- Darts Duel challenge flow
- Responsive mobile HUD
- React + Vite + React Three Fiber

## Run
npm install
npm run dev

This version uses virtual BET only. No real-money payment, cash-out, or token marketplace.

## Roadmap
1. Multiplayer lobby and presence
2. Server-authoritative wallet ledger
3. Fully playable darts gameplay
4. Profiles and cosmetics
5. Pool, racing, fighting and other town activities
6. Compliance, age gating and responsible-gaming controls before any real-money functionality
