# Bet City

Fresh small-town free-roam foundation. All 3D scene assets are sourced CC0 Kenney GLB files; no custom 3D models are used. The town has third-person movement, sprinting, roads, buildings, homes, trees, cars and NPCs. Betting, multiplayer and activities are intentionally removed from this reset so movement and world layout can be stabilized first. Poly Haven CC0 assets can be added later for PBR materials and HDRI lighting.
